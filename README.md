# Современные цифровые технологии

Учебный курс для направления **44.03.05 «Педагогическое образование (с двумя профилями подготовки)»**, 

профиль **«Информатика и дополнительное образование (робототехника)»**.

Курс формирует системное представление о современных цифровых технологиях и их применении в образовании, робототехнике и инженерном проектировании. Теоретическая часть охватывает цифровую трансформацию, Edge Computing, киберфизические системы и цифровые двойники, Интернет вещей, CAD и аддитивное производство, а также цифровые образовательные технологии. Практическая часть построена как сквозной проект **роботизированного образовательного комплекса**: от программной модели и IoT-телеметрии до проектирования физического узла и разработки цифрового учебного модуля.

## Цель курса

**Цель курса** — сформировать у студентов теоретические знания и практические навыки проектирования, программирования и применения современных цифровых технологий в задачах образовательной робототехники и цифровой образовательной среды.

В результате освоения курса студент должен уметь связывать физический объект, сенсоры, вычислительные узлы, сетевое взаимодействие, цифровую модель, исполнительные механизмы и образовательный интерфейс в единый воспроизводимый программно-аппаратный комплекс.

## Задачи курса

1. Сформировать понимание различий между **оцифровкой, цифровизацией и цифровой трансформацией**, а также роли данных в современных цифровых системах.
2. Освоить базовые архитектуры **Edge Computing, Cloud Computing, киберфизических систем и цифровых двойников**.
3. Научиться моделировать управляющую логику робототехнического узла с использованием **Python и конечных автоматов (FSM)**.
4. Освоить принципы **Интернета вещей (IoT)**, сенсорной телеметрии и обмена данными по MQTT.
5. Получить практические навыки работы с **ESP32, Raspberry Pi Pico W/WH** и другими учебными микроконтроллерными платформами.
6. Освоить основы **CAD-моделирования, прототипирования и подготовки моделей к FDM/FFF- и SLA/MSLA-печати**.
7. Научиться применять цифровые технологии при проектировании **интерактивных образовательных ресурсов и робототехнических учебных сценариев**.
8. Сформировать навыки выбора программного и аппаратного стека с учетом **воспроизводимости, надежности, безопасности, импортонезависимости и доступности инфраструктуры**.
9. Развить навыки проектного документирования, работы с Git и воспроизводимого представления результатов инженерно-педагогической деятельности.

- **ESP32 DevKit** — базовая IoT-платформа;
- **Raspberry Pi Pico W/WH** — RP2040 с Wi-Fi для MQTT-сценариев;
- **РОББО**, **MGBot** — учебные робототехнические платформы;
- **Wiren Board** — инженерный уровень IoT/Edge и промышленной автоматизации;
- сенсоры температуры, влажности, освещенности, расстояния, движения, тока и положения;
- DC-моторы, сервоприводы и шаговые двигатели с внешними драйверами.

### CAD и цифровое производство

- **КОМПАС-3D** — основной отечественный CAD;
- **FreeCAD** — Open Source альтернатива;
- **Polygon X**, **Ultimaker Cura**, **PrusaSlicer** — подготовка моделей к печати;
- FDM/FFF-принтеры **PICASO 3D**, **IMPRINTA Hercules** и совместимое оборудование;
- PLA — основной материал для учебного прототипирования, PETG — для функциональных деталей.

## Быстрый старт

Создание Python-окружения:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r 2026/infrastructure/requirements.txt
```

Для Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r 2026/infrastructure/requirements.txt
```

Проверка установленного окружения:

```bash
python 2026/infrastructure/check_environment.py
```

Запуск локального MQTT broker и Node-RED:

```bash
docker compose -f 2026/infrastructure/infra/docker-compose.yml up -d
```

После запуска:

- MQTT broker — порт `1883`;
- Node-RED — порт `1880`.
