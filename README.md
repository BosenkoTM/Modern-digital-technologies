# Современные цифровые технологии

Учебный курс для направления **44.03.05 «Педагогическое образование (с двумя профилями подготовки)»**, профиль **«Информатика и дополнительное образование (робототехника)»**.

Курс формирует системное представление о современных цифровых технологиях и их применении в образовании, робототехнике и инженерном проектировании. Теоретическая часть охватывает цифровую трансформацию, Edge/Cloud Computing, киберфизические системы и цифровые двойники, Интернет вещей, цифровое производство и аддитивные технологии, а также цифровые технологии в образовании.

Практическая часть курса реализована в формате **полностью виртуального лабораторного практикума** на Python в Jupyter Notebook / Google Colab. Для выполнения обязательных лабораторных работ физические роботы, микроконтроллеры, 3D-принтеры и специализированные стенды не требуются. В качестве готовых учебных моделей, алгоритмов и исходных файлов используются материалы репозитория [BosenkoTM/robotics-course](https://github.com/BosenkoTM/robotics-course/tree/2026).

## Цель курса

**Цель курса** — сформировать у студентов теоретические знания и практические навыки применения современных цифровых технологий для моделирования, анализа и проектирования образовательных и робототехнических систем.

В результате освоения курса студент должен уметь работать с цифровыми моделями объектов, виртуальными сенсорами и телеметрией, трехмерными моделями и параметрами аддитивного производства, а также проектировать виртуальные образовательные эксперименты.

## Задачи курса

1. Сформировать понимание процессов **оцифровки, цифровизации и цифровой трансформации** и роли данных в современных цифровых системах.
2. Освоить базовые понятия **Edge Computing, Cloud Computing, киберфизических систем и цифровых двойников**.
3. Научиться создавать и исследовать виртуальные модели робототехнических объектов средствами Python.
4. Освоить принципы **Интернета вещей (IoT)**, сенсорной телеметрии, структуры сообщений и анализа качества передачи данных.
5. Познакомиться с моделями сенсоров, алгоритмами управления и планирования движения мобильных роботов.
6. Освоить основы анализа **STL/URDF-моделей**, параметров FDM/FFF-печати и виртуальной подготовки деталей к аддитивному производству.
7. Научиться проектировать виртуальные учебные эксперименты и цифровые образовательные практикумы.
8. Развить навыки воспроизводимого вычислительного эксперимента, работы с Jupyter Notebook, Git и готовыми открытыми программными компонентами.

## Быстрый старт

Клонирование курса:

```bash
git clone https://github.com/BosenkoTM/Modern-digital-technologies.git
cd Modern-digital-technologies
```

Минимальное локальное окружение:

```bash
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установка базовых библиотек:

```bash
pip install jupyterlab numpy pandas matplotlib trimesh
```

Запуск JupyterLab:

```bash
jupyter lab
```

После запуска откройте notebook выбранной лабораторной в каталоге `2026/lw/lab_0X/` и задайте номер индивидуального варианта:

```python
VARIANT = 1
```

Допустимые значения: `1`–`25`.
