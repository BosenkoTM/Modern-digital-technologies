# Лабораторный практикум — «Современные цифровые технологии»

1. `lab_01` — цифровой двойник мобильного робота.
2. `lab_02` — виртуальные сенсоры и IoT-телеметрия.
3. `lab_03` — виртуальный анализ STL и подготовка к 3D-печати.
4. `lab_04` — виртуальный учебный практикум по автономной навигации.

Все работы выполняются полностью виртуально в Jupyter Notebook / Google Colab.
