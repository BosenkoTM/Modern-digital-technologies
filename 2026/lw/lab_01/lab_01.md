# Лабораторная работа № 1. Виртуальный цифровой двойник мобильного робота

**Раздел дисциплины:** «Цифровые технологии»  
**Формат:** полностью виртуально в Jupyter Notebook / Google Colab  
**Максимум:** 20 баллов

## Цель

Разработать виртуальный цифровой двойник двухколёсного мобильного робота и исследовать его движение, управление и реакцию на препятствия.

## Задачи

1. Использовать готовую кинематическую модель `DiffDrive`.
2. Использовать готовый `PIDController` для движения к цели.
3. Реализовать виртуальный датчик расстояния.
4. Реализовать FSM `IDLE → RUN → AVOID → GOAL/FAULT`.
5. Провести симуляцию и оценить траекторию по метрикам.

## Инструменты

- Python 3.10+;
- Jupyter / Google Colab;
- NumPy, Pandas, Matplotlib;
- готовые материалы `robotics-course`.
